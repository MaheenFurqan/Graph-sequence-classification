# Graph Sequence Classification

A C++ graph-based application that classifies sequences of cities using graph theory concepts.

The program uses a city graph represented by an adjacency matrix and determines whether a given sequence is a Walk, Trail, Path, Closed Walk, Circuit, or Simple Circuit.

## Features

- City graph representation using an adjacency matrix
- City sequence parsing
- Walk classification
- Trail classification
- Path classification
- Closed Walk classification
- Circuit classification
- Simple Circuit classification
- Sequence length calculation
- Interactive testing of custom city sequences
- Automatic grading of classification results

## Technologies Used

- C++
- Graph Theory
- Adjacency Matrix
- Arrays
- File Handling

## Files

- `main.cpp` — Main C++ source code containing the graph classification functions.
- `map.txt` — Contains the city names and adjacency matrix used by the program.

## How to Run

Make sure `main.cpp` and `map.txt` are located in the same working directory.

Compile and run `main.cpp`, then enter city sequences in the following format:

`ISLAMABAD->RAWALPINDI->SIALKOT`

The program displays the sequence length and its classification.
